Changes: selected RU/IR/CN public country ranges, represented without widening
as CIDRs; merged only adjacent exact coverage; encoded as sing-box SRS1 and
IPv4-only Xray text. Geosite and Re:filter inputs remain unchanged. The data's
CC BY4.0 rights are not restricted by the surrounding application licence.
No DB-IP endorsement is claimed.

Freshness: operators regenerate from a newly pinned monthly Lite CSV with this
recipe, validate coverage and publish through the existing signed APK update
channel. No startup Git download or unsigned update is introduced. Existing
offline users retain a verified bundle until they accept a signed app update.
