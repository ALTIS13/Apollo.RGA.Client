# Apollo.RGA: личный тестовый режим OlcRTC на A063

Дата: 2026-09-28. Статус: дополнение к подтверждённым проектам Access Bridge и автоперехода в ограниченной сети. Владелец разрешил личную тестовую сборку без списания трафика из общего лимита Remnawave, с отдельным журналом байтов, завершением соединения после отключения и автопереходом. Это **не** разрешение включать режим обычным подписчикам или менять production Remnawave.

## Граница режима

- Обычные VLESS/Hysteria 2 и прежняя ссылка подписки остаются неизменными. Личный экспериментальный OlcRTC появляется отдельным режимом только в opt-in debug APK `tech.gatealtas.rga.personal` и только для заранее привязанной установки A063. Package ID лишь изолирует установку от обычного Apollo.RGA; нельзя открывать режим по одному лишь имени устройства, debug-флагу, PSK, локальной настройке или наличию `olcrtc://` в JSON.
- Bridge подтверждает ту же Remnawave-подписку при привязке и перед каждым новым допуском. `ACTIVE`, срок действия и отзыв обязательны; общий Remnawave-лимит **не уменьшается** на тестовые OlcRTC-байты. У тестового режима нет отдельной месячной квоты. Короткий серверный допуск автоматически продлевается при действующей подписке. Native meter требует конечного технического предела на соединение: для личной сборки он установлен достаточно высоко (до 1 ТиБ), не списывается из подписки и не показывается как пользовательский остаток. Предел байтов не обновляется продлением допуска; если он когда-либо будет достигнут, нужен новый допуск и новая сессия.
- Допуск выдаётся сервером для одной привязанной установки, комнаты, страны и `OLCRTC_TEST` audience. Узел проверяет его при join, гасит повтор, соблюдает локальный deadline не позже срока подписки и не более пяти минут, периодически продлевает только после свежей проверки Bridge. Отказ Bridge/панели не создаёт новый допуск; действующая сессия прекращается к своему deadline. Отключение режима/подписки закрывает конкретную активную сессию, а не другие подключения.
- OlcRTC-трафик пишется в отдельный durable журнал по монотонным cumulative счётчикам с идентификатором сессии. После штатного disconnect журнал помечает завершение и последний **подтверждённый** high-water; неподтверждённый хвост обозначается `unconfirmed`, а не нулём. Журнал не подключается к общему бюджетному циклу и не меняет Remnawave traffic. Клиентские байты не являются источником допуска или учёта.
- Для теста используется выделенная существующая комната. Отключение закрывает клиентский TUN/SOCKS, серверную сессию и участие в комнате; процесс/контейнер не должен автоматически оживлять осиротевшую сессию. Текущий Telemost provider не доказывает удаление самой комнаты через API, поэтому **не обещаем физическое удаление комнаты**. Не создаём новую комнату при каждом подключении без подтверждаемого API удаления. Если владелец комнаты должен быть удалён, нужен отдельный provider contract и физическая проверка.

## Автопереход и возврат

На A063 обычный выбранный хост остаётся предпочтительным. При пропаже Wi-Fi на LTE сервис использует уже построенные привязанные к физической сети пробы и два раунда классификации: только подтверждённый отказ обычного транспорта вместе с доступной локальной сетью даёт запрос на OlcRTC. Неизвестный результат, сон, краткий обрыв и сбой TUN/bridge не являются доказательством ограниченной сети. Нельзя переключать без действующего серверного допуска и достижимого carrier. Возврат на VLESS/Hysteria 2 происходит после устойчивой проверки обычного пути; ручной выбор и отключение VPN имеют приоритет. Пользователю показываются «Проверяем сеть», «Переключаемся» и проверенное состояние, без ложного «Подключено» после одного SOCKS-ответа.

Передача зарубежного трафика не должна напрямую утекать при переключении: недиректные потоки блокируются, пока TUN и новый transport не проверены. RU/local остаются direct по действующей политике, `.cc` и `.at` принудительно proxy. Первый личный выпуск ограничивается подтверждённым IPv4/TCP; UDP/IPv6 не обещаются до физической проверки. Это свойство транспорта, а не искусственное ограничение подписки.

## Выпуск и доказательства

1. Локально: проверенный pinned OlcRTC fork + managed patch, воспроизводимая debug-сборка, server admission, тестовый журнал и закрытие сессии. Никаких секретов в APK, логах и исходниках.
2. Изолированно: отрицательные проверки чужой установки, повторного допуска, истечения, недоступности Bridge, выключения режима и обрыва reporter; lifecycle комнаты подтверждается только в пределах доступного provider API.
3. A063: одна старая ссылка, VLESS/Hysteria 2 в обычной сети, LTE с ограниченным доступом → OlcRTC, возврат на Wi-Fi, сон/разблокировка, ручное отключение, отсутствие живой серверной сессии после отключения и последний подтверждённый учёт. Отдельно проверить полный TUN-путь внешним UID, а не только SOCKS. Если какой-то пункт не доказан, тестовая сборка не описывается как готовая.
4. Первую личную APK допустимо установить вручную и затем заменить тем же package/signature. Обновление «по воздуху» — отдельная реализация с подписанным манифестом, проверкой hash/package/certificate и откатом; до неё не включать устаревший upstream updater.

Обычный выпуск для подписчиков по-прежнему требует общего учёта/отзыва, доказанного полного TUN, статуса в ограниченной сети и отдельного решения владельца. Личное исключение не переводит эти ворота в выполненные.
